# 🌿 گولند - فروشگاه آنلاین گل و گیاه

## 📋 معرفی پروژه

**گولند** یک فروشگاه آنلاین حرفه‌ای و لوکس برای فروش گل و گیاه با ویژگی‌های کامل مدیریت محتوا، سبد خرید، پرداخت آنلاین و پنل ادمین قدرتمند است.

## 🚀 شروع سریع

### 📥 پیش‌نیازها

- PHP 7.4 یا بالاتر
- MySQL 5.7 یا بالاتر
- Apache/Nginx
- Composer (اختیاری، برای نصب واسط‌ها)

### 🛠 نصب و راه‌اندازی

1. **کلون کردن ریپازیتوری:**
```bash
cd /path/to/your/webserver
git clone https://github.com/mrtz8bgy/goolland.git
cd goolland
```

2. **ایجاد دیتابیس:**
```sql
CREATE DATABASE goolland CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

3. **ایمپورت فایل SQL:**
```bash
mysql -u username -p goolland < database/goolland.sql
```

4. **تنظیمات اتصال به دیتابیس:**
   فایل `includes/config.php` را ویرایش کنید:
```php
$host = 'localhost';
$dbname = 'goolland';
$username = 'your_username';
$password = 'your_password';
```

5. **تنظیمات سایت:**
   از طریق پنل ادمین (`/admin`) می‌توانید تنظیمات سایت را انجام دهید.

6. **راه‌اندازی سرور:**
   - برای Apache: فایل را در دایرکتوری `htdocs` یا `www` کپی کنید
   - برای Nginx: تنظیمات سرور را برای پوشه پروژه تنظیم کنید

7. **دسترسی به سایت:**
   - سایت: `http://localhost/goolland`
   - پنل ادمین: `http://localhost/goolland/admin`

### 🔐 اطلاعات ورود به پنل ادمین

پس از نصب، می‌توانید با اطلاعات زیر وارد پنل ادمین شوید:
- **نام کاربری:** admin@goolland.ir
- **رمز عبور:** admin123

> ⚠️ **توجه:** حتما پس از اولین ورود، رمز عبور را تغییر دهید.

## 🗄 ساختار دیتابیس

## 🎨 ویژگی‌های فنی

### فناوری‌های استفاده شده
- **Backend:** PHP 7.4+
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Design:** Responsive Design, Mobile-First
- **Security:** Prepared Statements, CSRF Protection, Password Hashing

### ویژگی‌های امنیتی
- استفاده از Prepared Statements برای جلوگیری از SQL Injection
- هش کردن رمزهای عبور با استفاده از `password_hash()`
- حفاظت از CSRF با استفاده از توکن‌ها
- اعتبارسنجی ورودی‌ها و خروجی‌ها
- مدیریت سشن امن

### ویژگی‌های عملکردی
- کش کردن اطلاعات (Caching)
- بارگذاری تنبل تصاویر (Lazy Loading)
- بهینه‌سازی کوئری‌های دیتابیس
- فشرده‌سازی و مینیفای CSS/JS
