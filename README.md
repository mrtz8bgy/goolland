## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- PHP 7.4 یا بالاتر
- MySQL 5.7 یا بالاتر
- Apache/Nginx
- Composer (اختیاری)

### مراحل نصب

1. **کلون کردن ریپازیتوری**
   ```bash
   git clone https://github.com/mrtz8bgy/goolland.git
   cd goolland
   ```

2. **ایجاد دیتابیس**
   - یک دیتابیس MySQL ایجاد کنید
   - فایل `database/setup.sql` را در phpMyAdmin یا از طریق MySQL اجرا کنید

3. **پیکربندی اتصال به دیتابیس**
   فایل `includes/db.php` را ویرایش کنید:
   ```php
   $host = "localhost";
   $dbname = "نام_دیتابیس_شما";
   $username = "نام_کاربری_دیتابیس";
   $password = "رمز_عبور_دیتابیس";
   ```

4. **پیکربندی سایت**
   - به پنل مدیریت وارد شوید: `/admin/login.php`
   - نام کاربری: `admin`
   - رمز عبور: `Admin@2026!`
   - به بخش تنظیمات بروید و اطلاعات سایت را وارد کنید

5. **آپلود فایل‌ها بر روی سرور**
   - تمام فایل‌ها را بر روی هاست خود آپلود کنید
   - مطمئن شوید پوشه `assets/images/products/` قابل نوشتن است

## 🔧 پیکربندی

### تنظیمات دیتابیس
فایل `includes/db.php` را ویرایش کنید:
```php
$host = "localhost";
$dbname = "نام_دیتابیس";
$username = "نام_کاربری";
$password = "رمز_عبور";
```

### تنظیمات ایمیل
برای ارسال ایمیل، می‌توانید از تابع `mail()` PHP استفاده کنید یا کتابخانه‌هایی مانند PHPMailer را نصب کنید.

### تنظیمات پرداخت
سیستم پرداخت آنلاین را می‌توانید با درگاه‌های پرداخت ایرانی مانند زرین‌پال، پرداخت ملات و... یکپارچه کنید.

## 📊 دیتابیس

### جدول‌ها
- `admins` - مدیران سایت
- `settings` - تنظیمات سایت
- `categories` - دسته‌بندی‌ها
- `products` - محصولات
- `articles` - مقالات
- `users` - کاربران
- `orders` - سفارش‌ها
- `order_items` - آیتم‌های سفارش
- `reviews` - نقد و بررسی‌ها
- `contacts` - پیام‌های تماس

### اسکریپت ایجاد دیتابیس
فایل `database/setup.sql` حاوی تمام جدول‌ها و داده‌های پیش‌فرض است.

## 🎨 سفارشی‌سازی

### تغییر رنگ‌ها
برای تغییر رنگ‌های سایت، متغیرهای CSS در فایل `assets/css/style.css` را ویرایش کنید:
```css
:root {
    --bg: #04100b;
    --green: #22c55e;
    --green-light: #86efac;
    /* ... */
}
```

### تغییر فونت
برای تغییر فونت، لینک فونت گوگل را در فایل `includes/header.php` ویرایش کنید.
